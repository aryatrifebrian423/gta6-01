# Neon Palms: Low Tide

An open-world, GTA VI-inspired game set in Sunward Bay. Take on 10 missions with 8 named characters, drive 8 named vehicles, and collect 12 palm coins across a procedural 3D city. Explore on foot or behind the wheel; rising wanted tiers bring patrols, while weather and tides affect driving. Tune in to 3 radio stations as you roam.

## Run

Requires Node 22+. From the repository root, run:

```sh
node serve.ts
```

This serves the `game/` directory. Open [http://127.0.0.1:8080](http://127.0.0.1:8080).
